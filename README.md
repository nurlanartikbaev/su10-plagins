# SU10 plugins

Маркетплейс плагинов Claude Code для дизайн-системы SU10.

Сейчас в нём один плагин — `su10`, он приносит скилл `su10-design-system`: правила сборки
макетов в Figma, каталог компонентов, цвета и токены, подбор иконок, сборка таблиц данных
и аудит макета перед сдачей.

## Установка

Один раз добавить маркетплейс:

```
/plugin marketplace add nurlanartikbaev/su10-plagins
```

И поставить плагин:

```
/plugin install su10@su10-plugins
```

Всё. Скилл подхватится сам, звать его не надо — он срабатывает, когда речь заходит о сборке
экрана в SU10, выборе компонента или токена, о таблицах данных.

## Обновления

Правка доезжает до всех только вместе с **поднятой версией** в
`plugins/su10/.claude-plugin/plugin.json`. Установленная копия плагина лежит в каталоге,
привязанном к номеру версии, поэтому коммит без смены номера у остальных просто не применится —
проверено.

Чтобы обновления приезжали сами, добавьте в свой `~/.claude/settings.json`
в блок `su10-plugins` флаг `autoUpdate`:

```json
"su10-plugins": {
  "source": { "source": "github", "repo": "nurlanartikbaev/su10-plagins" },
  "autoUpdate": true
}
```

Тогда Claude Code при каждом запуске подтянет маркетплейс и обновит плагин.

Забрать вручную, если нужно прямо сейчас:

```
/plugin marketplace update su10-plugins
```

```
/plugin update su10@su10-plugins
```

После этого Claude Code просит перезапуск — до него старая версия остаётся активной.

## Правки

Скилл правят коллабораторы репозитория. Если доступа на запись нет — напишите владельцу:
что просили, что получилось, чего ждали. Скриншот макета помогает больше описания.

### Синхронизация у тех, кто правит

В репозитории лежит `tools/su10-autopush.sh` — он держит скилл в актуальном состоянии в обе
стороны: подтягивает правки остальных и публикует ваши. Поставьте его один раз:

```bash
cp tools/su10-autopush.sh ~/.claude/hooks/ && chmod +x ~/.claude/hooks/su10-autopush.sh
```

И пропишите в `~/.claude/settings.json`:

```json
"hooks": {
  "Stop": [
    { "hooks": [ { "type": "command", "command": "~/.claude/hooks/su10-autopush.sh", "timeout": 60 } ] }
  ]
}
```

Скрипт ждёт репозиторий в `~/Documents/su10-plugins` — если склонировали в другое место,
поправьте `REPO` в первых строках.

Дальше после каждой вашей правки: подтягиваются чужие коммиты, поднимается patch-версия,
в шапке `SKILL.md` проставляется, кто обновил, делается коммит и пуш. Если чужие правки
конфликтуют с вашими, скрипт не лезет напролом — скажет разобрать вручную.

Для владельца порядок такой: правка в `plugins/su10/skills/su10-design-system/`, подъём версии
**в трёх местах** (шапка `SKILL.md`, поле `description` во фронтматтере, `version` в
`plugins/su10/.claude-plugin/plugin.json`), запись в `references/changelog.md`, коммит и пуш
в `main`. Без подъёма версии правка не применится ни у кого — установленная копия привязана
к номеру.

## Доступ

Репозиторий публичный — для установки не нужно ни доступа к нему, ни авторизации
на GitHub. Достаточно двух команд выше.

Имя репозитория — `su10-plagins`, через «a». Это опечатка, но адрес рабочий;
имя маркетплейса внутри Claude Code при этом правильное — `su10-plugins`.
