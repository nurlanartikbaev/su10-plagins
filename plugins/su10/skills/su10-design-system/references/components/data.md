# Компоненты: данные

Справочник скилла `su10-design-system`. **Когда открывать:** ставишь ячейки таблицы, `Badge`, `Avatar`, `Stories`, `Scrollbar`. Сборка таблицы целиком: `data-tables.md`.

### Данные

**TableHeaderCell** `1470:15469` — заголовок колонки с подписью. `Sort` Off / Available / Ascending / Descending.
`Off` — колонка не сортируется, иконки нет. `Available` — сортировка доступна, но не применена: полоски вразнобой, приглушённый цвет. `Ascending` / `Descending` — сортировка включена: полоски убывают или возрастают сверху вниз, подпись и иконка темнеют. Состояние читается сразу по двум признакам — по рисунку полосок и по тому, что активная колонка темнее. Отсортированной может быть только одна колонка таблицы, у остальных `Available` или `Off`.

**TableHeaderCellSlot** `1473:15445` — заголовок колонки без подписи, содержимое кладётся в слот `content`: чекбокс «выбрать все», одиночная иконка, подпись вместе с кнопкой. Сортировки у него нет. Высоту задаёт содержимое слота.

**TableRow** `1683:270` — строка таблицы. `State` Rest / Hover / Selected · `Devider` on / off · `cells` SLOT.
Даёт строке подложку и состояния, которых у ячеек нет: `Rest` — без заливки, `Hover` — `surface/3-layer`, `Selected` — фирменная подложка `surface/brand-transparent-static` (teal, с 13.11; шапка таблицы — светлый teal/10). Разделитель рисует строка, поэтому ячейкам внутри ставят `Devider = off`, а последней строке — `Devider = off` у самой строки.

**TableCell** `1163:10817` (содержимое в слоте `content`) · **TableFooter** `1244:10626` (`Type` Counted/Uncounted). Подпись «Показывать по:» видимая, в коде связана с Select через `aria-labelledby`.
В ячейку кладут: текст, `Badge`, `Tag`, `Avatar`, `Text Button`, `CheckBox`.

**Badge** `1078:14902` — статус рядом с данными, его **не нажимают**. `Size` L/M/S · `Signal` Neutral/Info/Success/Warning/Error/Accent · `Label` TEXT · `Show Label` BOOLEAN. `Show Label = false` даёт бейдж-иконку — отдельного `Only Icon` для этого не нужно. **Длинный текст обрезается многоточием** — бейдж в одну строку и не растёт.
Badge или Tag: если элемент кликабельный (выбирается, снимается крестиком) — это `Tag`; если он только показывает статус записи — `Badge`.

**Avatar** `1224:65` — `Size` XL/L/M/S/XS · `Type` Placeholder/Initials/Picture, картинка в слоте `picture` · `Show Status` — точка «на связи» в правом нижнем углу, размер по аватару (18/14/12/10/8), со своей обводкой цветом подложки: `avatar/status-ring`, толщина по размеру 3/2/2/2/1,5, токена толщины нет. Иконка заглушки — `Bold / Users / User`, ключ `0a9f6bc2b3bd1e7d7f6f5c2ce0711b7a4815eea1`. Счётчика и стека внахлёст нет. Кольцо истории вокруг аватара — это отдельный компонент `Stories`, а не свойство аватара.

**Stories** `1871:115` — история пользователя: аватар в кольце статуса и подпись под ним.
`Size` XL/L/M/S/XS · `State` New/Viewed · `Label` TEXT · `Show Label` BOOLEAN.
`New` — история не просмотрена, кольцо красится стилем `StoriesGradient`; `Viewed` — просмотрена,
кольцо нейтральное на `border/secondary`. Истории без кольца не бывает: если истории нет вообще,
ставится обычный `Avatar`, а не этот компонент.

**Размер повторяет лестницу `Avatar`** — кольцо всегда равно аватару + 8 (`size/stories-ring-*`),
толщина всегда `stroke/border-stroke-bold`, чистый зазор до аватара 3. Поэтому на мелких размерах
кольцо читается тяжелее, чем на XL, — это свойство постоянной толщины, а не ошибка. XL — ряд
историй на главной, под него компонент и рисовался; L и M — компактные списки; S — шапка и строка
таблицы; XS — плотные перечисления, подпись там почти всегда выключают через `Show Label`.
Подпись берёт `Caption 1` на XL/L/M и `Caption 2` на S/XS, отступ до неё — `Space-8` и `Space-4`
соответственно.

Аватар внутри — обычный инстанс `Avatar`: тип (Picture / Initials / Placeholder) и картинка
правятся прямо в нём, подменять его не надо. Ряд историй — горизонтальный автолейаут с шагом
`Space-12`, непросмотренные первыми, ряд встык к полю экрана и прокручивается.

**Scrollbar** `1010:13966` — `Orientation` Vertical/Horizontal. Ставить только там, где прокрутка есть.
