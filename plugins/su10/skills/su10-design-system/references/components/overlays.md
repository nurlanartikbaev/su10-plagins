# Компоненты: оверлеи и подсказки

Справочник скилла `su10-design-system`. **Когда открывать:** открываешь `Dialog`, `DesktopDrawer`, `MobileBottomSheet`, `ContextMenu`, `Tooltip`, `Popover`, `Coachmark`.

### Оверлеи — страница `Overlay`

**`Show Close` есть у всех трёх оверлеев** и по умолчанию включён; при выключении заголовок занимает всю ширину шапки. **Крестик — дублирующий выход, а не единственный: любой из трёх закрывается кликом по подложке `Overlay`**, шторка вдобавок свайпом вниз. Выключение крестика человека внутри не запирает — его выключают там, где закрытие ведёт кнопка подвала и лишний выход в шапке только шумит. Единственный случай, когда выходов не остаётся, — панель, поставленная **без подложки**: тогда крестик и подвал одновременно выключать нельзя. Ключи разные: `MobileBottomSheet` `Show Close#2379:0`, `Dialog` `#2381:0`, `DesktopDrawer` `#2381:1`.

Анатомия у всех трёх одинаковая: шапка (вложенный `Heading` + крестик на `Text Button`) → слот `content` → подвал с кнопками. Общие свойства: `content` (SLOT), `Show Header`, `Show Footer`, `Show Secondary Button`. Заголовок и подзаголовок правятся во вложенном `Heading`.

**Пустую середину выключают: `Show Content=false`** (решение владельца 11.11). Есть у `Dialog` (`Show Content#4334:0`) и `MobileBottomSheet` (`Show Content#4334:1`), по умолчанию включено. Если в слот `content` класть нечего (подтверждение из заголовка, подзаголовка и кнопок), область контента скрывают свойством. Пустой слот оставляет между шапкой и кнопками около 50 px пустоты: так сдавать нельзя. Слой `Content` руками в инстансе не скрывают: только свойством.

**DesktopDrawer** `1400:336` — боковая панель. `Size` S/M/L: `size/drawer-width-s` 280/360, `-m` 320/420, `-l` 360/640. Когда человек продолжает работать с тем же списком и нужен контекст рядом. Прокручивается только слот. Шире L не делать — это уже отдельный экран. Скруглена сторона контента (`radius/border-radius-400`), сторона у края экрана прямая.

**MobileBottomSheet** `1387:27` — шторка снизу. Скругление только сверху, `Show Handle` — ручка перетаскивания. Действия внизу: верх экрана на телефоне недосягаем. Меню и списки в слоте `content` собираются из строк **`ListItem`** на Fill, люди и группы — из **`ProfileItem`** (см. «Списки»). Нажатие на строку-переход или строку-действие закрывает шторку, переключение `Toggle` в строке — нет. Свайп закрывает, если шторку протащили больше чем на 25 % высоты или резко смахнули. `Home Indicator` внутри мастера — рамка устройства: в коде это системный отступ, полоску рисует iOS.

**Dialog** `1387:52` — окно по центру для короткой задачи или подтверждения. Ширина — `size/dialog-width` (343 / 480). У подтверждающего вторая кнопка обязательна, а кнопки — ответ на заголовок: не «Да / Нет», а «Удалить / Отмена».

**Overlay** `1399:10274` — затемнение под панелью. `Platform` Mobile 375×852 / Desktop 1440×1024. Обязательно для Dialog и шторки; для Drawer — если за ним нельзя работать.

### Контекстное меню — страница `ContextMenu`

**ContextMenu** `1793:8` — команды над конкретным объектом: строкой таблицы, карточкой, файлом. Правый клик или кнопка «…» рядом с объектом; закрывается после первого выбора. От кнопки меню — отступ `Space-4`. `content` SLOT, ширина `size/context-menu-width` (240), поверхность и тень как у `Dropdown`.

**ContextMenuItem** `1792:49` — одна команда. `Signal` Default/**Critical** · `State` Rest/Hover/Disabled · `Label` и `Shortcut` TEXT · `Show Shortcut` · `Left Icon` / `Right Icon` INSTANCE_SWAP с `Show`-булями. Высота фиксированная — `height/height-1000`. Ставится **на Fill**. Правая стрелка — признак подменю и с горячей клавишей вместе не показывается.

**ContextMenuSection** `1792:50` — заголовок группы, высота `height/height-650`. Нужен, когда пунктов больше шести или они из разных наборов; иначе хватает `Divider`.

Подпись пункта — глагол в инфинитиве («Удалить», не «Удаление»). Разрушающий пункт **один**, стоит последним и отделён `Divider`. Больше десяти пунктов — это уже не меню.

**Граница с соседями:** `Dropdown` выбирает значение для поля, `MenuItem` — постоянная навигация в сайдбаре, `Popover` — панель с содержимым и кнопками, `ContextMenu` — разовые команды без состояния выбора. На мобильном вместо меню берут `MobileBottomSheet` **со строками `ListItem`**: в строку 36 px у края экрана пальцем не попасть. Строка списка на экране, в шторке или панели — тоже `ListItem`, а не `ContextMenuItem`.

Одновременно открыт **один** оверлей. Крестик закрывает без сохранения, сохранение живёт в подвале.

**Несохранённые изменения — всегда диалог** (решение владельца 02.11). Есть изменения — любой выход (крестик, подложка, свайп, Esc) сначала показывает `Dialog` «Закрыть без сохранения?»: панель заменяется диалогом, поэтому оверлей остаётся один. Кнопки — «Закрыть» (Primary, `Signal=Error`) и «Продолжить» (Secondary): «Продолжить» возвращает панель с введёнными данными. Длинные подписи в диалог 480 не помещаются (решение владельца 06.11). Изменений нет — закрывается сразу. В этом диалоге крестика нет (`Show Close=false`, решение владельца 11.11): крестик и «Закрыть» делали противоположное. Контента в нём тоже нет: `Show Content=false`, иначе в середине остаётся пустое место. Esc и клик по подложке — как «Продолжить».


### Подсказки — страница `Tooltip`

**Tooltip** `1388:18` — одна фраза по наведению. `Position` Top/Bottom/Left/Right — сторона от элемента, стрелка смотрит на него. `Text`, `Show Arrow`. Без действий и ссылок — до неё нельзя доехать курсором. Подсказка не заменяет подпись.

**Popover** `1389:2` — панель у элемента по клику: фильтр, быстрые настройки, карточка сущности. Слот `content`, `Show Header`, `Show Footer`, `Show Secondary Button`, ширина `size/popover-width`. Не затемняет экран. Одновременно открыт один.

**Coachmark** `3902:404` (страница `Coachmark`, паспорт `CoachmarkPassport` `3904:146`, с 03.11) — подсказка онбординга у конкретного элемента: заголовок, описание, шаг и кнопки. Лежит поверх затемнения с вырезом. `Position` Top/Bottom/Left/Right — с какой стороны от цели стоит, хвостик смотрит на цель; Left и Right только на десктопе · `Align` Start/Center/End · `Media` SLOT + `Show Media` · `Step` TEXT + `Show Step` · `Show Secondary`. Наружу выведены `Heading`, `Secondary action`, `Next`. По-казахски «Дальше» — «Келесі», «Пропустить» — «Өткізіп жіберу», «Понятно» — «Түсінікті», шаг — «1 / 4».
- Ширина — `size/coachmark-width` (327 / 330). Цвет — семантика `surface/2-layer` напрямую: отдельная группа `color/component/coachmark` потребовала бы пересоздать 30 групп токенов ради алфавита.
- **Хвостик над произвольной целью:** переместить его в инстансе нельзя, но поле можно. У слоя `Tail row` отвязать и задать `paddingLeft` (у Left/Right — `paddingTop`) так, чтобы центр хвостика совпал с центром цели: `tr.setBoundVariable('paddingLeft', null); tr.paddingLeft = 113`. Правое поле ряда при этом обнуляют так же: иначе длинное смещение растягивает компонент шире токена.
- **Текст задают свойствами**, а не через `characters` у вложенного текста: `Heading` — `Title#1386:0`, `Subtitle#1386:4`, `Next` — `Label#273:46`, `Secondary action` — тоже `Label#273:46`.
- **Кнопки:** `Next` — Primary, есть всегда, на последнем шаге называется «Понятно». Вторая кнопка одна, `Button` S `Weight=Tertiary, Signal=Info`: на первом шаге «Пропустить» закрывает весь тур, со второго шага на её месте «Назад» возвращает на шаг (решение владельца 03.11). **Короткий вид:** у `Heading` выключен `Show Subtitle`, в подсказке выключены `Show Step` и `Show Secondary`.
- **Вырез и кольцо — компонент `Spotlight`** (страница `Spotlight`, паспорт `SpotlightPassport`, с 06.11): `Radius` 8/12/16/20/Circle. Инстанс ставят поверх цели: размер = цель + 4 с каждой стороны, `Radius` = радиус цели + 4. Затемнение `overlay/scrim` уходит за край на 4000 px — экран обрезает его. Кольцо `border/brand` 2 px (до 13.11 `border/info`). Клик по вырезу открывает цель и завершает тур, клик по затемнению ничего не делает. Самодельные вырезы через `figma.subtract` больше не рисуют.
