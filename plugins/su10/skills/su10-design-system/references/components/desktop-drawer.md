# DesktopDrawer

Справочник скилла `su10-design-system`.

**DesktopDrawer** `1400:336` — боковая панель. `Size` S/M/L: `size/drawer-width-s` 280/360, `-m` 320/420, `-l` 360/640. Когда человек продолжает работать с тем же списком и нужен контекст рядом. Прокручивается только слот. Шире L не делать — это уже отдельный экран. Скруглена сторона контента (`radius/border-radius-400`), сторона у края экрана прямая. **Нативный слот `content` есть только у `Size=M`:** у S и L на его месте обычный фрейм, содержимое туда не положить. Содержимому в слоте задают `FIXED` 380: на `FILL` оно схлопывается по содержимому. Подробности — `references/plugin-api.md`, раздел «Баги компонентов — проверено, обходить».
