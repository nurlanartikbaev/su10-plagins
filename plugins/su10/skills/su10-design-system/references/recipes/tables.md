# Рецепты: таблицы

Справочник скилла `su10-design-system`. Все рецепты: `recipes/INDEX.md`.

## Рецепты сборки

**Таблица на телефоне — по задаче** (решение владельца 04.11). Значения сравнивают по столбцам — таблица с прокруткой вбок, без `Scrollbar`. Запись читают целиком — карточки: строка становится `Island` с `ListItem`, главное значение в заголовке, остальное в описании, статус — `Badge`. Примеры — раздел «Телефон» в паспорте Table.

**Таблица.** Вся таблица кладётся в `Island` с нулевыми полями: своей рамки и заливки у неё нет, инстансу `Island` ставят `clipsContent = true`. `TableHeaderCell` в строку заголовка, `TableFooter` снизу. Фильтры над таблицей — селекты и `SegmentedControlRow` размера S в одну строку.
Сборка бывает двух видов: **строками** — `TableRow` со слотом, если у строки есть состояния (выбор чекбоксом, наведение); **колонками** — вертикальные стопки `TableCell`, если состояний нет и важнее один раз задать ширину колонки. Смешивать в одной таблице нельзя. Подробности — `references/data-tables.md`, раздел «Таблицы данных».

**Таблица — главный блок десктопного экрана** (решение владельца 23.11). Экран 1024, таблица до кнопки чата (снизу `Space-128`), шапка таблицы и `TableFooter` на месте, строки прокручиваются во фрейме между ними, справа вертикальный `Scrollbar`. Сборка — `data-tables.md`, раздел «Таблица на всю высоту экрана».
